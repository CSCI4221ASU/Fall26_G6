# CampusConnect Prototype Design

## Project 2 - Group 6

### Product Overview

CampusConnect is a platform designed to help college students stay informed about campus events, student organizations, and activities happening on campus. The goal of the application is to make campus information easy to find in one place.

## Prototype 1 - Home Screen

The CampusConnect Home Screen is the main screen students will see when using the application. It provides quick access to Upcoming Events, Student Organizations, Campus Activities, and the user's profile.

The home screen also displays upcoming events so students can quickly see what is happening around campus.

## Prototype 2 - Campus Events Screen

The Campus Events Screen allows students to browse upcoming events. Events can include academic events, social events, sporting events, service activities, workshops, and other campus programs.

Each event can display information such as the event name, date, time, and location.

## Prototype 3 - Student Organizations Screen

The Student Organizations Screen allows students to discover organizations available on campus. Students can browse different organizations and select "View Details" to learn more about an organization.

Organizations can also be separated into categories to make them easier to find.

## Users

The primary users of CampusConnect are college students. Students can use the application to:

- Find upcoming campus events.
- Discover student organizations.
- Find campus activities.
- View event dates, times, and locations.
- Access information about organizations.
- Stay involved with the campus community.

## Prototype Navigation

The prototype demonstrates how a student could navigate through CampusConnect.

1. The user starts on the Home Screen.
2. Selecting Upcoming Events takes the user to the Campus Events Screen.
3. Selecting Student Organizations takes the user to the Student Organizations Screen.
4. The navigation menu allows the user to return Home or access Events, Organizations, and their Profile.

## Design

The prototype uses a simple mobile layout with clearly labeled buttons and navigation options. The goal of the design is to make CampusConnect easy for college students to understand and use.
