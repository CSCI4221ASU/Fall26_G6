## Section 1: Features

The Final Grade Calculator will help students understand their current grades and determine what scores they need to achieve their desired final course grades.

### Feature 1: Current Grade Calculator
**Description:** The application will allow students to enter their assignment, quiz, test, and other category grades to calculate their current course grade.

### Feature 2: Weighted Grade Calculation
**Description:** The application will calculate grades using category weights set by the instructor, helping students understand how each category contributes to their overall course grade.

**Assigned To:** Jalen Davis  
**Status:** Ready for consideration  
**Sprint:** Project 3

### Feature 3: Final Exam Score Predictor
**Description:** The application will allow students to enter their desired final course grade and calculate the score they need on the final exam to reach that goal.

**Assigned To:** Malachi Johnson

## Section 2: Personas

### Persona 1: The Student Who Wants to Improve
**Name:** Alex Johnson  
**Description:** Alex is a college student who wants to improve their course grade and needs to know which exam scores will help achieve that goal.

**Goals:** Track current grades, identify areas for improvement, and determine the final exam score needed to earn a desired grade.

**Assigned To:** Jakedrian Wright

### Persona 2: The Student Managing Multiple Courses
**Name:** Taylor Smith  
**Description:** Taylor is a college student taking several courses and needs a quick, simple way to calculate grades without doing calculations manually.

**Goals:** Save time, reduce calculation errors, and understand current academic performance.

**Assigned To:** Jalen Davis

### Persona 3: The Student Preparing for the Final Exam
**Name:** Jordan Williams  
**Description:** Jordan is preparing for a final exam and wants to know the minimum score needed to earn a target course grade.

**Goals:** Set a realistic grade target, plan study time, and understand the impact of the final exam.

**Assigned To:** Malachi Johnson

## Section 3: Scenarios

### Scenario 1: Checking the Current Course Grade
Alex enters grades for completed assignments, quizzes, and tests into the calculator. The application calculates the current course grade and displays the result. Alex uses the result to identify whether additional effort is needed to improve performance.

**Assigned To:** Jakedrian Wright

### Scenario 2: Calculating a Weighted Course Grade
Taylor enters grades for different course categories and their corresponding weights. The application calculates the weighted course grade and displays the result so Taylor can understand how each category affects overall performance.

**Assigned To:** Jalen Davis

### Scenario 3: Planning for the Final Exam
Jordan enters the current course grade, the final exam's course weight, and a desired final course grade. The application calculates the exam score needed to reach that target and informs Jordan if the target is not mathematically achievable.

**Assigned To:** Malachi Johnson

## Section 4: User Stories

### User Story 1: Calculate My Current Grade
**As a** college student,  
**I want** to enter my grades for completed coursework,  
**So that** I can see my current course grade and understand my academic progress.

**Acceptance Criteria:**
- The user can enter grades for completed coursework.
- The application calculates and displays the current grade.
- Invalid grade entries are identified and explained.

**Assigned To:** Jakedrian Wright

### User Story 2: Calculate My Weighted Grade
**As a** college student taking multiple courses,  
**I want** to calculate my grade using category weights,  
**So that** I can understand how assignments, quizzes, tests, and other categories affect my overall grade.

**Acceptance Criteria:**
- The user can enter grades and their corresponding category weights.
- The application calculates the weighted grade correctly.
- The application validates the inputs and identifies invalid weight totals.

**Assigned To:** Jalen Davis

### User Story 3: Find the Final Exam Score I Need
**As a** student preparing for a final exam,  
**I want** to enter my target course grade and see the exam score I need,  
**So that** I can set a realistic goal and plan my studying.

**Acceptance Criteria:**
- The user can enter a target course grade.
- The application uses the current grade and final exam weight to calculate the required exam score.
- The application indicates when the target is impossible to achieve or has already been reached.

**Assigned To:** Malachi Johnson
